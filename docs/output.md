# inpred/tso500_v2_reference_preparation: Output

## Introduction

This document describes the output produced by the pipeline. Files are written beneath `--outdir`, with subdirectories based on the process or tool that generated them.

Only files generated by enabled process `publishDir` rules are copied to the results directory. Temporary intermediate files in Nextflow's work directory are not included.

## Pipeline overview

The pipeline performs the following stages:

- [Target preparation](#target-preparation) — prepare and split the TSO500 panel intervals.
- [Read and allelic counts](#read-and-allelic-counts) — collect GATK4 count data.
- [Panel of normals](#panel-of-normals) — create and apply the normal-sample reference model.
- [Variant calling and recalibration](#variant-calling-and-recalibration) — call, normalize, and filter variants.
- [Segmented and filtered outputs](#segmented-and-filtered-outputs) — generate copy-number and heterozygous-site references.
- [Pipeline information](#pipeline-information) — save run reports and software versions.

### Target preparation

This stage prepares the reference intervals used for read-count collection.

<details markdown="1">
<summary>Output files</summary>

- `bedtools/`
  - `*_slop.bed`: Panel regions expanded by `--extension_limit`.
  - `*_complement.bed`: Regions complementary to the original panel.
  - `*_merged.bed`: Merged target or complement regions.
  - BAM-derived BED and coverage BED files.
- `split_targets/`
  - `*_split.bed`: Final expanded, merged, and split target intervals.
- `position_count/`
  - `*_position_count.tsv`: Per-position coverage information used while extending targets.

</details>

The final `*_split.bed` file is used as the interval list for subsequent GATK4 processing.

Intermediate chromosome-size and sorted-BED files are disabled in `publishDir` and remain in the Nextflow work directory.

### Read and allelic counts

GATK4 processes the normal BAM files and collects read counts across the prepared intervals.

<details markdown="1">
<summary>Output files</summary>

- `gatk4/`
  - `*_RD.bam`: BAM files with read-group metadata.
  - `*_RD.bai`: BAM indexes.
  - `*.hdf5`: GATK4 read-count data.
  - `*.tsv`: GATK4 allelic-count data.
  - `*.interval_list`: Preprocessed interval list.
  - GVCF and indexed VCF files for normal samples.
- `bedtools/`
  - Coverage and BAM-to-BED intermediates.

</details>

One HDF5 read-count file is produced per normal sample. Allelic counts are collected at filtered, recalibrated variant sites.

### Panel of normals

The normal-sample read counts are combined into a panel of normals and used to denoise each normal sample.

<details markdown="1">
<summary>Output files</summary>

- `gatk4/`
  - `*_sample_pon.hdf5`: Panel-of-normals model.
  - `*_standardizedCR.tsv`: Standardized copy-ratio counts.
  - `*_denoisedCR.tsv`: Denoised copy-ratio counts.
  - `*.modelFinal.seg`: Final segmented copy-ratio calls.
  - `*.hets.tsv`: Heterozygous-site model segments.

</details>

### Variant calling and recalibration

Normal GVCFs are imported into GenomicsDB, jointly genotyped, recalibrated with VQSR, normalized, and filtered.

<details markdown="1">
<summary>Output files</summary>

- `gatk4/`
  - `*.g.vcf.gz`: Per-sample GVCF files.
  - `*.g.vcf.gz.tbi`: GVCF indexes.
  - `*.vcf.gz`: Joint-genotype and recalibrated VCF files.
  - `*.tbi`: VCF indexes.
  - `*.recal`, `*.idx`, `*.tranches`: VQSR recalibration data.
  - `*_plots.R`: Optional VQSR plotting script.
- `bcftools/`
  - `*_biallelic.vcf.gz`: Biallelic-normalized VCF.
  - `*_biallelic.vcf.gz.tbi`: Biallelic VCF index.
- `extract_filtered_gatk_calls/`
  - `*_pass_snp.bed`: Passing SNP intervals.
  - `*_pass_snp.vcf`: Passing SNP calls before compression.
- `htslib/`
  - Compressed and indexed passing-SNP VCF files.

</details>

### Segmented and filtered outputs

The panel of normals and filtered SNP intervals are combined to produce the final copy-number and heterozygous-site references.

<details markdown="1">
<summary>Output files</summary>

- `gatk4/`
  - `*.modelFinal.seg`: Segmented copy-ratio calls.
  - `*.hets.tsv`: Heterozygous-site calls.
- `filter_hets_tsv/`
  - `*_filtered.hets.tsv`: Heterozygous sites retained at or above `--minimum_depth`.

</details>

The filtered heterozygous-site TSV is used as a reference input by the downstream TSO500 v2 post-processing pipeline.

### Pipeline information

<details markdown="1">
<summary>Output files</summary>
